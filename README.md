# 猫猫助手 (Nekomimi)

基于 Android 无障碍服务的聊天文本改写工具，从零重写的 v2 版本。

在聊天软件输入框中自动应用文本替换规则、断句追加与随机颜文字，支持任意聊天应用（QQ / 微信 / Telegram / WhatsApp / 钉钉 / Discord / 飞书 / Slack 等）。

> v2 用 Kotlin + Jetpack Compose 从零重写：重点解决原版的无障碍服务掉线问题（前台服务保活 + 自愈闹钟 + 熔断器 + 崩溃日志），并大幅扩展规则引擎（正则 / 随机 / 动态占位符）。

## 功能

**规则引擎**
- 字面替换：`原词=替换词`（支持全角 ＝ / →）
- 正则替换：`re:模式=替换`（支持 `$1` 捕获组）
- 随机替换：`你=主人|殿下|亲亲`（每次随机选一个）
- 动态占位符：`{time}` `{time:HH:mm:ss}` `{date}` `{week}` `{random}` `{random:1-100}`

**改写效果**
- 断句追加：按标点分句，句末追加自定义文本（支持随机：`喵|喵呜|喵喵`）
- 句末随机颜文字：内置 116 个猫咪颜文字（按心情分类），可自定义
- 预设风格包：萌系 / 傲娇 / 吐槽 / 脏话净化，一键应用（覆盖或追加，含效果预览）

**配置**
- 多套配置方案（Profile）：设置页 / 首页一键切换，通知栏「下一个配置」轮换
- 两种处理模式：标点触发（推荐）/ 实时处理（流式防抖）
- 作用范围：目标应用白名单 + 排除黑名单（留空 = 所有应用）
- 隐私与防误改：自动跳过输入法、桌面、系统设置；密码框永不处理

**稳定性（长期使用设计）**
- 前台服务保活 + 掉线检测通知（一键恢复）
- 自愈闹钟：AlarmManager 15 分钟唤醒 + 开机自启，进程被杀也能自动重建
- 熔断器：应用异常风暴 / 写入风暴自动熔断，防崩溃防刷屏
- 全局崩溃捕获：崩溃堆栈落盘可查
- 配置冗余：文件备份 + 损坏自动恢复
- 轻量化事件处理：节点缓存 + 遍历预算，避免 ANR
- 电池优化白名单引导、内置日志查看器、优雅停机

## 构建

```
./gradlew assembleDebug        # 调试包
./gradlew assembleRelease      # 发布包（R8 压缩，默认调试密钥签名）
```

产物：`app/build/outputs/apk/debug/nekomimi-<版本>.apk`、`app/build/outputs/apk/release/nekomimi-<版本>.apk`

最新 Release：https://github.com/Verlintas/nekomimi/releases/latest

## 使用

1. 安装 APK 并打开应用
2. 首页开启无障碍服务「猫猫助手（聊天文本改写）」
3. （可选）设置页应用预设风格包或手写规则 → 保存
4. 在聊天软件输入框打字，自动改写

> 提示：首次使用建议把应用加入电池优化白名单（首页有引导），并允许通知（掉线提醒用）。

## 测试

