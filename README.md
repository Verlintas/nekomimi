# 猫猫助手 (Nekomimi)

基于 Android 无障碍服务的聊天文本改写工具 —— 猫猫助手 v2 全新重写版。

在聊天软件输入框中自动应用文本替换规则、断句追加与随机颜文字，支持任意聊天应用（QQ/微信/Telegram/WhatsApp/钉钉/Discord/飞书/Slack 等）。

> v2 从零重写：Kotlin + Jetpack Compose，重点解决原版的无障碍服务掉线问题（前台服务保活 + 掉线检测 + 轻量化事件处理 + 崩溃日志），并扩展规则引擎（正则替换 / 随机替换）。

## 功能

- **文本替换规则**：字面替换（`原词=替换词`）、正则替换（`re:模式=替换`，支持捕获组）、随机替换（`你=主人|殿下|亲亲`）
- **断句追加**：按中文/英文标点分句，句末追加自定义文本（默认"喵"）
- **句末随机颜文字**：内置 50+ 猫咪颜文字，可自定义
- **两种处理模式**：标点触发（推荐）/ 实时处理
- **作用范围**：目标应用白名单 + 排除黑名单（留空 = 所有应用）
- **隐私与防误改**：自动跳过输入法、桌面、系统设置；密码框永不处理
- **稳定性**：前台服务保活、掉线检测通知、电池优化白名单引导、内置日志查看

## 构建

```
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/nekomimi-0.1.0.apk`

## 使用

1. 安装 APK 并打开应用
2. 开启无障碍服务「猫猫助手（聊天文本改写）」
3. 配置规则与作用范围 → 保存
4. 在聊天软件输入框打字，自动改写
