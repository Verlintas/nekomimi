# 猫猫助手 (Nekomimi)

基于 Android 无障碍服务的聊天文本改写工具，从零重写的 v2 版本。

在聊天软件输入框中自动应用文本替换规则、断句追加与随机颜文字，支持任意聊天应用（QQ / 微信 / Telegram / WhatsApp / 钉钉 / Discord / 飞书 / Slack 等）。

> v2 用 Kotlin + Jetpack Compose 从零重写：重点解决原版的无障碍服务掉线问题（前台服务保活 + 自愈闹钟 + 熔断器 + 崩溃日志），并大幅扩展规则引擎（正则 / 随机 / 动态占位符）。

## 功能

**规则引擎**
- 字面替换：`原词=替换词`（支持全角 ＝ / →）
- 正则替换：`re:模式=替换`（支持 `$1` 捕获组）
- 随机替换：`你=主人|殿下|亲亲`（每次随机选一个）
- 动态占位符：`{time}` `{time:HH:mm:ss}` `{date}` `{week}` `{random}` `{random:1-100}`

**改写效果**
- 断句追加：按标点分句，句末追加自定义文本（支持随机：`喵|喵呜|喵喵`）
- 句末随机颜文字：内置 116 个猫咪颜文字（按心情分类），可自定义
- 预设风格包：萌系 / 傲娇 / 吐槽 / 脏话净化，一键应用（覆盖或追加，含效果预览）

**配置**
- 多套配置方案（Profile）：设置页 / 首页一键切换，通知栏「下一个配置」轮换
- 两种处理模式：标点触发（推荐）/ 实时处理（流式防抖）
- 作用范围：目标应用白名单 + 排除黑名单（留空 = 所有应用）
- 隐私与防误改：自动跳过输入法、桌面、系统设置；密码框永不处理

**稳定性（长期使用设计）**
- 前台服务保活 + 掉线检测通知（一键恢复）
- 自愈闹钟：AlarmManager 15 分钟唤醒 + 开机自启，进程被杀也能自动重建
- 熔断器：应用异常风暴 / 写入风暴自动熔断，防崩溃防刷屏
- 全局崩溃捕获：崩溃堆栈落盘可查
- 配置冗余：文件备份 + 损坏自动恢复
- 轻量化事件处理：节点缓存 + 遍历预算，避免 ANR
- 电池优化白名单引导、内置日志查看器、优雅停机

## 使用

1. 安装 APK 并打开应用
2. 首页开启无障碍服务「猫猫助手（聊天文本改写）」
3. （可选）设置页应用预设风格包或手写规则 → 保存
4. 在聊天软件输入框打字，自动改写

> 提示：首次使用建议把应用加入电池优化白名单（首页有引导），并允许通知（掉线提醒用）。

## How it works（工作原理）

```
你打字 "我来了" ──▶ 无障碍服务收到输入框文本变化事件
                         │
                         ▼
                  范围过滤（白名单/黑名单，跳过输入法/密码框）
                         │
                         ▼
                  规则引擎：替换规则（字面/正则/随机）
                          → 断句追加 → 颜文字 → 动态占位符展开
                         │
                         ▼
                  通过系统无障碍 API 写回输入框
              输入框变成 "本喵来了喵~ (=^.^=)"
```

1. **事件监听**：通过 Android 无障碍服务接收 `TYPE_VIEW_TEXT_CHANGED`（输入框文本变化）、窗口切换、点击事件
2. **范围过滤**：按配置的目标应用白名单/排除黑名单过滤；自动跳过输入法、桌面、系统设置；**密码框（`isPassword`）永不处理**
3. **改写引擎**：读取输入框当前文本 → 按顺序应用替换规则 → 断句追加 → 句末随机颜文字 → 展开动态占位符（`{time}` 等）
4. **写回**：通过系统无障碍 API `ACTION_SET_TEXT` 将结果写回输入框，并把光标移到末尾
5. **增量跟踪**：差分维护"用户原始输入"，只在用户新增内容时重新改写，避免重复追加；检测到用户删除装饰（如删掉"喵~"）时尊重删除、不再补回
6. **两种模式**：标点触发（句末标点时处理，推荐）/ 实时处理（输入停止后防抖处理）

## 隐私与无障碍权限声明

**为什么需要无障碍权限？**

Android 平台上，无障碍服务是唯一允许应用读取/写入**其他应用**输入框文本的官方 API（输入法方案需要用户切换输入法，Shizuku 方案需要 ADB 授权）。本应用的文本改写功能必须依赖它——这也是所有同类工具（自动化、翻译、输入增强）的通行做法。

**本应用拿到无障碍权限后做什么 / 不做什么：**

| | 说明 |
|---|---|
| ✅ 只做 | 在你允许的目标应用输入框内，按你的规则改写文本 |
| ✅ 本地处理 | 全部处理在本机完成 |
| ❌ 不联网 | **应用不含 INTERNET 权限，物理上无法上传任何数据**（可自行查看 AndroidManifest.xml） |
| ❌ 不读聊天记录 | 只读取"聚焦输入框"的当前文本用于改写，不扫描/存储消息记录 |
| ❌ 不碰隐私数据 | 不申请通讯录/短信/通话/位置/相册/麦克风等任何敏感权限 |
| ❌ 不改密码框 | `isPassword` 节点永不处理 |
| ❌ 不拦截按键 | 不监听、不记录任何键盘输入 |
| ❌ 不访问输入法 | 自动跳过输入法窗口与包名，不读取候选词 |

**可审计**：代码完全开源（AGPL-3.0），所有权限与行为均可自行核对；也可以随时用「暂停」开关或直接关闭无障碍服务停止全部处理。

**如果你不信任无障碍类应用**：Android 系统设置里可查看「无障碍 → 已下载的服务 → 猫猫助手」，随时可关。
